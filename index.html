Кейсы и проекты

Интеграция веб-формы с Telegram и CRM через Serverless-прокси

Инструменты: JavaScript (Fetch API), Cloudflare Workers, Telegram Bot API, Webhooks, Git

Задача: Настроить безопасную мгновенную передачу лидов со статического сайта в мессенджер и CRM без раскрытия API-токенов на фронтенде.
Результат: Реализовал бессерверный обработчик на Cloudflare Workers с защитой CORS и хранением ключей в переменных окружения. При отправке заявки с формы ниже уведомление за 1 секунду улетает в Telegram и параллельно создаёт сделку в CRM через входящий вебхук.

Проектирование воронки продаж и автоматизация учёта лидов

Инструменты: Битрикс24 / amoCRM, CRM-формы, анализ бизнес-процессов

Задача: Исключить потерю обращений и выстроить прозрачный путь клиента от первого касания до закрытия сделки.
Результат: Спроектировал этапы воронки продаж, настроил обязательные поля карточки клиента, автоматическую фиксацию источника обращения и распределение задач при смене стадий.

Разработка адаптивного сайта-портфолио с поддержкой тёмной темы

Инструменты: HTML5, CSS3 (CSS Variables), JavaScript, GitHub Pages

Задача: Создать быстрый, лёгкий и адаптивный сайт с современным интерфейсом без использования тяжелых фреймворков и конструкторов.
Результат: Сверстал семантическую структуру с нуля, реализовал переключение светлой/тёмной темы с сохранением выбора пользователя в localStorage и настроил публикацию на GitHub Pages.
